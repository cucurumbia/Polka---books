Полка домашней библиотеки

О проекте

«Полка домашней библиотеки» — это веб-приложение для учёта личной коллекции книг. Оно позволяет хранить информацию о книгах, отслеживать читательский прогресс и собирать собственную библиотеку в одном месте.

Проект разработан в рамках учебной практики с использованием PHP и фреймворка Yii2. Для хранения данных используется база данных MySQL.

Основные возможности

* Каталог книг — просмотр списка книг, информации об авторах и годах издания.
* Поиск книг — поиск произведений по названию или автору.
* Личная библиотека — учёт книг и их читательских статусов.
* Избранное — возможность сохранять понравившиеся книги.
* Отзывы и оценки — возможность делиться впечатлениями о прочитанных произведениях.
* Заметки — сохранение личных записей, связанных с книгами.
* Профиль пользователя — хранение информации об аккаунте.
* Администрирование — управление информацией о книгах.

Структура базы данных

Для хранения информации используются следующие таблицы:

Таблица	Назначение
user	Данные пользователей
book	Информация о книгах
genre	Жанры книг
book_genre	Связь книг с жанрами
review	Отзывы и оценки
note	Личные заметки
status	Статусы чтения
user_book	Связь пользователей с книгами
